# Voice Impersonation Detection System (VIDS)

Final-year B.Sc. Computer Science (AI & DS) project — a CNN-based
voice deepfake detector.

CNN (Professor K, 4.58M params) classifies voice clips as
**Real Human** or **AI-Generated** from mel-spectrograms,
with acoustic evidence, calibrated confidence, and UNCERTAIN verdicts.

## ⬇ Download the app

**[Download VIDS Setup.exe for Windows](https://github.com/gkkishore26/Voice-Impersonation-Detection-System/releases)**
— no admin needed. The full **Quick Start guide** (install, usage,
performance, limitations) is on the release page.

## For developers

## Run (web demo)
```powershell
python webapp/app.py
# open http://127.0.0.1:5000
```

## Train
```powershell
python training/train.py --epochs 45 --batch 32        # full (needs dataset/mega)
python training/finetune.py --epochs 10 --lr 1e-4      # field round
python evaluation/evaluate.py                          # metrics + figures
```

## Desktop build
```powershell
Software\build_exe.bat     # PyInstaller (needs Software/exe_env, see Software/setup_exe_env.bat)
# then compile Software/installer/VIDS_Setup.iss with Inno Setup 6
```

## Layout
- `webapp/` — Flask backend + UI (templates/static/js)
- `training/` — CNN, preprocessing, evidence engine, dataset builders
- `evaluation/` — metrics, confusion matrix, curves, file-level tests
- `model/` — weights (`professor_k.pth`) + `presets/` restorable snapshots
- `dataset/` — corpora + manifests (see `Software/` for the installer)
- `Report/` — college submission report (Word, regenerated by `scripts/make_report.py`)
- `Software/` — desktop launcher, build scripts, installer project, `Setup.exe`
- `tests/` — backend/stream/field/regression tests
