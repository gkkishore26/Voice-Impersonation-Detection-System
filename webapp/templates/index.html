    06 / FAQ

    How accurate is Professor K?+

    98.7% validation accuracy with precision 1.000 on held-out clips from the training distribution. Accuracy on brand-new AI generators can differ — see the next question.

    Why did my AI voice score as Real?+

    The model was trained on a narrow set of TTS voices, so it memorised those fingerprints instead of general deepfake patterns. A multi-generator retrain (WaveFake + in-the-wild data) is in progress to fix exactly this.

    What files can I upload?+

    WAV, MP3, M4A, OGG or FLAC — 3 seconds to 5 minutes, up to 20 MB. Clips over 15 seconds switch to segmented analysis automatically.

    How does segmented analysis work?+

    Long audio is sliced into 3-second blocks. Each block is scored independently, then majority vote decides the verdict — the segment map shows every block.

    Can I save the report?+

    Yes — the Print Report button produces a clean black-on-white report with verdict, probabilities, spectrogram and segment map.
